# 🛒 Multivendor E-Commerce Website

An end-to-end full-stack multi-vendor e-commerce platform featuring role-based access management, product browsing, order processing, and administrative controls.

🚀 **Live Demo:** [https://multivendor-e-commerce.vercel.app/](https://multivendor-e-commerce.vercel.app/)

---

## 🛠️ Tech Stack & Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript, Handlebars (HBS)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose)
- **Authentication:** JSON Web Tokens (JWT), Password Hashing
- **Deployment:** Vercel

---

## 👥 User Roles & Access Control

The platform supports **5 distinct user roles**:

1. **Customers (Users):** Browse products, filter/sort, manage cart & wishlist, buy now, track orders, and leave reviews.
2. **Sellers:** Add, edit, or delete products, view total sales & product count, and process customer orders.
3. **Admin:** Manage sellers, users, and employees (CRUD operations), approve/reject product listings, and oversee platform activity.
4. **Product Managers:** Assist admin with reviewing, approving, rejecting, or deleting product listings.
5. **User Managers:** Assist admin with activating or deactivating user and seller accounts.

---

## ✨ Key Features

- **Authentication & Security:** Secure JWT login, password hashing, and strict role-based authorization.
- **Shopping Experience:** Product search, category filtering, price sorting, wishlist, dynamic cart, and direct "Buy Now" checkout.
- **Order & Review System:** Real-time order status tracking and verified product ratings/reviews.
- **Role-Based Dashboards:** Dedicated management panels for Admin, Sellers, and Managers.
